# Documentation

This folder contains reference materials, decision records, reviews, and other supporting documentation related to projects, experiments, and professional development activities.

## Folder Structure

### briefs/
Short summaries, executive briefs, and condensed write-ups intended for quick consumption.

### decisions/
Decision records documenting important choices, trade-offs, assumptions, and rationale.

### reviews/
Retrospectives, project reviews, lessons learned, and assessment documents.

## Documentation Principles

Documents in this folder should:

- Be written in Markdown whenever possible.
- Include dates when appropriate.
- Capture context, decisions, and outcomes.
- Be organized so future readers can quickly understand the history and rationale.

## Related Areas

| Folder | Purpose |
|----------|----------|
| `analysis/` | Research, analytics, and exploratory work |
| `data/` | Data files and datasets |
| `scripts/` | Automation and utility scripts |
| `drafts/` | Work-in-progress content |
| `scratch/` | Temporary notes and experiments |

## Maintenance

Periodically review documents and archive or remove outdated content that is no longer relevant.
